# SakhiCircle UI direction options

Generated with the built-in ImageGen tool on 2026-08-18. These are visual direction boards, not implemented screens. Retain their color, typography, and content ideas, but reinterpret every layout as a mobile-first responsive PWA.

## Shared prompt constraints

- High-fidelity SakhiCircle web/PWA product UI for phone and desktop browsers.
- Designed for Indian women aged 45+; dignified, encouraging, rooted, and modern.
- Exactly three icon-plus-label destinations: Today, My Circle, and Mentors.
- Large readable type, strong contrast, safe-area-aware spacing, 48px controls, voice plus text alternatives, visible help and Hindi controls.
- Use a bottom tab bar below 900px; on desktop, place the navigation rail at the viewport's left edge and center the content in the remaining canvas.
- Avoid the existing magenta-heavy split panel, senior-care or medical imagery, generic dashboards, glassmorphism, gradients, beige AI styling, excessive pills, tiny text, and ornamental stereotypes.
